⭐ How to Update the Live Website on GitHub in 30 Seconds:

  1. Make your vehicle changes above (Add, Edit, change Status to Sold, or Delete).
  2. Click the gold "Download vehicles.js" button above (or "Copy vehicles.js Code").
  3. Open your GitHub repository: github.com/pridetakudzwa74/HUS-MOTORS (or your active repository).
  4. Navigate to src/data/vehicles.js.
  5. Click the pencil icon (✏️) to edit, replace the contents with your downloaded/copied file, and click "Commit changes".
  6. Within 60–90 seconds, your live website automatically updates on GitHub Pages!
Note on Hosting & CMS: Because GitHub Pages is free static hosting, passwords cannot be verified on the server. If you prefer a full online login without touching GitHub files, see the CMS setup instructions in OWNER-EDITING-GUIDE.md (Decap CMS / Supabase).
